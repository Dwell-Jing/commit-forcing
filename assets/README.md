The current paper figures are supplied as editable SVG, vector PDF, and PNG previews.
The PDFs and SVGs below match the manuscript exports; PNGs are rendered from those PDFs.

All windows include the current block. Nonrecent sources are model-dependent; the diagrams do not imply one shared physical cache. The selected frames are generated outputs, not schematic illustrations.

## Reproduction

Python dependencies are NumPy, Matplotlib, and Pillow. The vector schematic renderers also use `rsvg-convert` and `pdftoppm` (Poppler). Run from the repository root:

```bash
python assets/source/make_teaser.py
python assets/source/make_method.py
python assets/source/make_committing_content_age.py
python assets/source/make_committing_impulse.py
python assets/source/make_qualitative_grid.py
```

The recency renderer validates all 1,200 released per-video Subject c2c values before drawing the recorded means. The propagation renderer reads the recorded means and prompt-bootstrap intervals from `source/kv_propagation.csv`. The qualitative renderer verifies all twelve source-frame hashes and dimensions. Numerical inputs are retained at their recorded precision; no measurements are regenerated by these scripts. Font and Matplotlib versions can affect export metadata and PDF text metrics.

Canonical export hashes, input hashes, and figure provenance are in [`manifest.json`](manifest.json) and the corresponding `*.provenance.json` files. Qualitative selection and per-case scores are recorded in [`source/qualitative_grid_inputs/source.json`](source/qualitative_grid_inputs/source.json).
